## File Structure (as-shipped)

- **src/main.ts** — Entry point. Creates Phaser.Game instance (config: scene, physics arcade, scale FIT). Uses RundotGameAPI for logging. No explicit SDK init; SDK is used after game is created.
- **src/scenes/HelloWorldScene.ts** — Default scene. Replace or extend for your game. Shows CDN asset loading, physics, and pointer input.
- **src/style.css** — Global styles.
- **index.html** — Mount point `#app` for Phaser; optional `#dialog-overlay` for HTML overlays (e.g. dialogs). Script entry: `/src/main.ts`.
- **public/** — Small static assets; referenced via relative paths or loaded in preload().
- **public/cdn-assets/** — Large assets deployed to CDN. Load at runtime via `RundotGameAPI.cdn.fetchAsset('filename.png')`, then feed blob URL to `this.load.image()` and `this.load.start()`.
- **vite.config.ts** — Vite + `rundotGameLibrariesPlugin()`. Build target es2022 (SDK uses top-level await).
- **game.config.json** — Generated by `rundot init`. Do not edit manually.

## Key Patterns

- **Game loop** — Managed by Phaser. Add logic in the scene’s `update()` method.
- **Input** — Use Phaser input: `this.input.on('pointerdown', ...)` or `gameObject.on('pointerdown', ...)`. For overlay UI (e.g. dialog close), DOM (`document.getElementById`, `addEventListener`) is acceptable.
- **Assets** — In-scene: load in `preload()`, use in `create()`. CDN: `const blob = await RundotGameAPI.cdn.fetchAsset('name.png')`, `URL.createObjectURL(blob)`, load into Phaser, then `URL.revokeObjectURL(blobUrl)` in loader `complete` callback; call `this.load.start()` after queueing.
- **RundotGameAPI** — Import from `@series-inc/rundot-game-sdk/api`. Use `RundotGameAPI.log()` for debug in RUN.game host; `RundotGameAPI.cdn.fetchAsset()` for CDN assets. No separate init step in main.
- **Scenes** — Extend `Phaser.Scene`, pass to `scene: [MyScene]` in game config in main.ts. Use `super("scene-key")` in constructor.

## What to Modify

- **New game logic** → New scene in `src/scenes/`, add to `scene` array in main.ts config.
- **New small assets** → Add to `public/`, load in scene’s `preload()`.
- **New large/CDN assets** → Add to `public/cdn-assets/`, load at runtime with `RundotGameAPI.cdn.fetchAsset()` and the loader pattern above.
- **Game config (resolution, physics)** → Phaser.Game config in main.ts.
- **Overlay UI** → Add markup in index.html, show/hide via DOM in the scene (e.g. classList add/remove).
